Running a boolean set operation (e.g. intersection) between two attacker-supplied geometries through GEOS's public overlay API can crash the process when one of the operands is a "mixed-dimension" input containing a zero-dimensional (point-like) component that is not itself directly a Point object.

Root cause: GEOS's next-generation overlay engine has a dedicated code path for combining inputs whose dimensions differ (e.g. one operand contributes point geometries while the other contributes areal/linear geometries). As part of preparing the point-valued side of such an overlay, the engine walks the immediate children of that operand's geometry and, for each child, assumes it can only ever be a Point — it takes the child pointer coming back from that iteration and hard-casts it directly to a Point pointer (a C++ static downcast) with no runtime check that the child is actually of that type, before reading its coordinate. This assumption silently depends on the input having already been "flattened" one level so that every immediate child really is a bare Point. If the point-valued operand is instead a collection that still has a nested sub-collection as one of its own children (rather than that nested collection's points having been flattened into direct children first), the walk hands back a pointer to that nested collection object, not to a Point. The unconditional downcast then reinterprets a collection object as a Point object. Because both are polymorphic C++ classes with distinct vtables, the sanitizer's runtime type-checking instrumentation catches the mismatch the instant the mis-typed pointer is used as a Point and aborts with an invalid-downcast / bad-cast diagnostic, rather than the program silently corrupting memory or segfaulting. No prior validation step in the overlay call path rejects such not-fully-flattened mixed-dimension inputs before they reach this coordinate-extraction step, so a crafted pair of geometries (e.g. supplied as WKB/WKT to the library's intersection entry point) that puts a sub-collection where a bare point is expected is sufficient to trigger the crash, with no other precondition.
