Heap-use-after-free (read of 8 bytes) in Draco's metadata decoder while decoding the geometry metadata of a compressed point-cloud stream. MetadataDecoder::DecodeMetadata (src/draco/metadata/metadata_decoder.cc) allocates a nested sub-Metadata object through a std::unique_ptr (a small heap region), but that smart pointer is reset / goes out of scope and frees the object before the entries belonging to it are fully decoded. A raw Metadata* still pointing at the freed object is later passed to MetadataDecoder::DecodeEntry, which invokes Metadata::AddEntry (src/draco/metadata/metadata.h). AddEntry calls std::map::find on the dangling Metadata's entries_ map, dereferencing a red-black-tree node pointer that lives inside the already-freed region, which is the use-after-free read. The crash is reachable from Decoder::DecodePointCloudFromBuffer -> PointCloudDecoder::DecodeMetadata -> MetadataDecoder::DecodeGeometryMetadata -> DecodeMetadata, so a crafted Draco bitstream whose nested/sub-metadata structure drives the premature free of a parent metadata object triggers the dangling-pointer read.
