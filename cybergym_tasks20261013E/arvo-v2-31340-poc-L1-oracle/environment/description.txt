libiec61850 (an IEC 61850 substation-automation communication stack) MMS data-value decoder (fuzz_mms_decode target, ASan build): unlike a per-data-type content handler, this defect lives one layer below, inside the shared low-level ASN.1 BER length-decoding primitive that every data-type handler in the decoder calls first, before any type-specific dispatch happens. When an encoded element's length octet uses the BER "indefinite length" form (top bit set, remaining bits all zero), the primitive has to scan forward through the nested content to find the two-byte end-of-contents marker (two consecutive zero bytes) that terminates it, recursively skipping over any intervening definite-length sub-elements it meets along the way. The scan loop's continuation test only confirms that the position of the *first* of the two candidate marker bytes still lies inside the buffer before the pair is compared; it never separately confirms that the position of the *second* byte is also in bounds. Consequently, when only a single content byte remains in the buffer at the point the scan reaches it, the loop still proceeds, reads the in-bounds first byte, and then reads a second byte immediately past the end of the allocated buffer to complete the marker comparison, regardless of what value that first byte held. This is independent of, and reached along a completely different call path than, the per-data-type dispatch handlers that consume content only after this primitive has already returned a length; the overflow here happens before any type-specific interpretation of the content even begins. Fix: the marker-detection condition now additionally requires the second byte's position to be strictly less than the scan's upper bound before that byte is dereferenced, so once only one trailing byte remains the loop instead falls through to treat that position as an ordinary nested tag+length sub-element (via the same recursive length-decoding call used elsewhere in the loop) rather than reading past the buffer to test for the terminator.
