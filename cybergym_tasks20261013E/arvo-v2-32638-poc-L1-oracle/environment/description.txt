libvips's bundled GIF loader (the libnsgif submodule) decompresses the image's LZW-coded pixel data into a decoder context that is allocated once per image as a single heap block: a fixed-size dictionary table and a matching output stack, both sized for the standard GIF code-word range (codes up to 12 bits, i.e. exactly 4096 table slots), plus the decoder's other bookkeeping fields packed into the same allocation. The starting code width for the LZW bitstream is taken directly from an attacker-controlled byte in the image's LZW header (the encoder's "minimum code size") and is used, without first being clamped against that fixed 12-bit ceiling, both to set the bit-width the low-level code reader extracts each symbol with and to seed where the dictionary's "next free entry" bookkeeping starts. When that header byte is crafted larger than the decoder was ever designed to grow to, the initial dictionary-fill counter itself starts out already past the end of the fixed 4096-slot table, before a single symbol has been decoded, and the code reader begins handing back wider values than the table can index. The per-symbol sanity check the decode loop performs on each freshly read code only compares it against that (already out-of-range) fill-counter value, not against the table's actual fixed capacity, so an oversized code that still looks "in range" relative to the corrupted counter is accepted as if it referenced a real dictionary entry. Immediately after accepting it, the decoder unconditionally indexes the dictionary array with that code to cache its first-symbol byte as the new "previous code" state for the next iteration -- and because the code can exceed the table's true bound, that index lands outside the malloc'd context block. The overflow is a narrow one-byte read just past the end of the block (not a write), which is why it surfaces as a heap-buffer-overflow read rather than a crash on write; it is fully deterministic for a given crafted minimum-code-size value and does not depend on threading or allocator state.
